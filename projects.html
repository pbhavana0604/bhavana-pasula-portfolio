How the frontend was built

Reference style taken from general portfolio best practice: a clear hero with role + location + relocation, a runnable demo above the fold, a project grid, an experience timeline, and a skills list — no stock photos, no fake testimonials, no invented metrics. Technically: semantic HTML5, one h1 per page, skip link, landmarks, real labels, error summaries linked to fields, aria-live status, visible focus, and compiled SCSS design tokens in frontend/scss/ (_tokens.scss, _components.scss, _base.scss, _mixins.scss). The CSS in wwwroot/css/main.css is checked in, so the site runs with no Sass or Node build step.
