Run it in 2 minutes

git clone https://github.com/pbhavana0604/bhavana-pasula-portfolio.git
cd bhavana-pasula-portfolio
dotnet restore IowaBenefitsPortal.sln
dotnet run --project src/IowaBenefitsPortal/IowaBenefitsPortal.csproj --urls http://localhost:5111

Then open http://localhost:5111/ — this page. Try the live demo: Benefits portal demo → Apply (demo) → get a reference like IA-DEMO-2026-000201 → Check status. Seeded demo references also work: IA-DEMO-2026-000101, IA-DEMO-2026-000102.

API quick check, with the app running: GET /health, GET /api/services, POST /api/applications, GET /api/applications/IA-DEMO-2026-000101. Versioned routes (/api/v1/…) work identically.
