Code samples

Healthcare — dashboard + FHIR pattern

code-samples/csharp/HealthcareDashboard.cs — capacity summary, SignalR-style live update shape, FHIR R4 patient summary mapping (name, identifiers redacted in samples), and an AI-summary request that requires human review before display. No PHI, no real patient data.

Banking — loan API pattern

code-samples/csharp/LoanApi.cs — intake DTO with validation, idempotency key handling, underwriting state machine (Received → UnderReview → Approved/Declined), and an event payload for Kafka/MSK. No real applicant data.

Airline — reservation pattern

code-samples/csharp/FlightReservation.cs — fare search result, reservation hold with expiry, itinerary change/cancellation rules, and an idempotent nightly load record.

Support — ticket pattern

code-samples/csharp/SupportTicket.cs — ticket creation, assignment, SLA deadline calculation, escalation, and audit history. Plus the legacy Web Forms sample and modern equivalent in code-samples/legacy/.

Runnable core — already in this repo

  • src/IowaBenefitsPortal/Controllers/ — versioned REST API, validation, 201/400/404 handling
  • src/IowaBenefitsPortal/Services/ — application + fictional eligibility rules, cleanly separated from HTTP
  • src/IowaBenefitsPortal/Repositories/ — in-memory default + SQL Server (parameterised queries, stored procedure in database/sql/)
  • src/IowaBenefitsPortal/Middleware/ — global exception handling, security headers, request logging
  • frontend/scss/ — design tokens, mixins, base and components; compiled CSS checked in
  • tests/IowaBenefitsPortal.Tests/ — xUnit: eligibility rules, API responses, HTML accessibility smoke tests
